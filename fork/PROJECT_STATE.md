Refactors to do before a port: [audit.md §6](research/audit.md#6-recommended-fork-refactors-before-the-port).

## Deployment

al runs upstream's image (`cy01/blackhole:latest`) as the compose stack `/opt/stacks/decypharr`, config in `/opt/conf/decypharr` (secrets; never read the values), behind Pangolin. Real-Debrid + TorBox Pro, DFS mount at `/mnt/decypharr`, no usenet providers, SMB/NFS unused; torrents are added through DMM. **The fork is not deployed yet.**

Fork changes that affect deployment: WebDAV needs auth when `use_auth` is on, TLS verification is on, Hearsay is off unless opted in, `rate_limit` is a hard cap, and secrets must be re-entered when their destination changes.
